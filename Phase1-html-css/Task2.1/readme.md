# Abacus Convention Center

A responsive landing page for a convention center, built with plain HTML and CSS from a given design.

**Live demo:** https://convention-center-task2-1.netlify.app

## Sections

- Navbar and hero banner with a "Book Now" button
- "Every moment is Precious" about section
- Four event packages, with Wedding Plus highlighted
- Happy client testimonials
- FAQ (open and close with `<details>`, no JavaScript)
- Footer with app store links

## Tech Used

- HTML5
- CSS3 (Flexbox, media queries)
- Hosted on Netlify

## Project Structure

```
├── index.html
├── style.css
├── README.md
└── Assets/        (images)
```

## Run Locally

1. Download or clone the project.
2. Open `index.html` in your browser.

## Features

- Fully responsive for desktop, tablet and mobile
- Hover and click effects on buttons
- No JavaScript used
